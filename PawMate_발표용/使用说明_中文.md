# PawMate｜期末发表用网站（独立版本）

这个文件夹命名为 **`PawMate_발표용`**（发表用），用于五分钟课堂演示，**不是最终完整版**。请保留此文件夹，未来可以另建 `PawMate_최종본` 上传更完整的网站，两者互不覆盖。

## 电脑上打开

解压后进入 `PawMate_발표용` 文件夹，双击 `index.html`，用 Safari 或 Chrome 打开。不要移动文件夹里的 CSS、JS 或图片。

## 演示步骤

1. 点击首页的 `돌봄 매칭 체험하기`。
2. 点击示例 `고양이 방문 돌봄`，再点 `요청 조건 정리하기`。
3. 检查分析出的条件，选择 `요청 등록하고 제공자 찾기`。
4. 展示推荐、排序、收藏和个人资料，选择一位并确认模拟匹配。
5. 模拟开始照护、勾选清单、写照护日志、结束照护。
6. 提交评价，在 `이용 내역` 查看记录。

## 上传到已有 GitHub 课程仓库

仓库：`https://github.com/mingyang1019ck-tech/2026Fall-1`

在仓库里的 `PawMate_발표용` 文件夹上传 `index.html`、`style.css`、`script.js`、`favicon.svg`、`.nojekyll`、`assets` 文件夹及这两个说明文件。确保文件路径是 `PawMate_발표용/index.html`，**不要把 ZIP 压缩包直接上传当作网站**。

然后到 `Settings → Pages`，选择 `Deploy from a branch`，分支为 `main`，目录为 `/(root)`。发布成功后可以通过以下地址访问（尚未验证部署）：

`https://mingyang1019ck-tech.github.io/2026Fall-1/PawMate_발표용/`

## 重要说明

这一版本的韩语需求分析、匹配推荐是**基于 JavaScript 的规则逻辑**，并未接入生成式 AI 模型。所有照护人员、价格、服务状态都是演示资料；网站不提供真实预约、付款或聊天功能。浏览器会保存模拟记录，需要重新演示时点击 `데모 초기화`。
