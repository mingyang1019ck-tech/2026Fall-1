## 시연 기능

한국어 돌봄 요청 정리, 규칙 기반 제공자 추천, 필터·정렬, 예약 시뮬레이션, 돌봄 기록, 후기, 이용 내역.

**주의:** 실제 생성형 AI API 연결 없이 JavaScript 규칙 기반으로 작동하는 교육용 프로토타입입니다. 가상 데이터만 사용하며 실제 예약과 결제는 제공하지 않습니다.
