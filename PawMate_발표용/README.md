# PawMate — 기말 발표용 웹사이트 (발표용 데모)

**2026년 2학기 기말 발표를 위한 독립 실행형 시연 버전**입니다. 이 폴더는 이후 제출할 기능 확장판과 구별하기 위해 `PawMate_발표용`이라는 이름으로 보관합니다.

## 직접 실행

이 폴더 안의 `index.html`을 Safari 또는 Chrome 브라우저에서 엽니다. `assets/`, `script.js`, `style.css`는 함께 보관해야 합니다.

## 5분 발표 시연 순서

1. 홈에서 **돌봄 매칭 체험하기** 클릭
2. **고양이 방문 돌봄** 예시 선택 → **요청 조건 정리하기** 클릭
3. 분석 결과 확인 → **요청 등록하고 제공자 찾기** 클릭
4. 제공자 정렬·필터·프로필 확인 → **시연용 매칭 확정**
5. **돌봄 시작 시연하기** → 체크리스트·기록 → **돌봄 완료 시연하기**
6. 후기 저장 → **이용 내역** 확인

## 데모의 기능과 범위

- HTML / CSS / JavaScript 기반의 정적 웹사이트
- 한국어 요청 조건 분석 및 규칙 기반 매칭 (생성형 AI API와 연결되지 않음)
- 필터·정렬·관심 제공자 저장, 예약 시뮬레이션, 돌봄 관리 및 후기
- `localStorage`로 사용자의 시연 데이터를 현재 브라우저에 저장
- 인물·후기·요금·서비스 기록은 가상 데이터이며 실제 예약·결제·메시지 발송은 제공하지 않음
